# Documentation assets

These files support the README and release notes. They are not app-bundle
resources; runtime metadata and icon inputs stay in [`Resources/`](../../Resources/).

| Location | Purpose |
| --- | --- |
| `brand/cover.png` | Current README cover |
| `demo.gif` | README dictation demonstration |
| `releases/vX.Y.Z/` | Version-specific screenshots and recordings |
| `brand/archive/` | Retained reference artwork not used by the current README |

The archive preserves the earlier cover, logo proposal and light-logo export.
They are distinct design files, not verified duplicates; moving them here does
not declare them unusable or authorize deletion. The active icon-generation
source remains `Resources/Nuvi_Logo.svg`.
