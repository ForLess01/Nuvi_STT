# Nuvi 2.2.0

Nuvi 2.2 focuses on more predictable dictation control, audio capture
lifecycle safety, and a more expressive floating pill.

## Highlights

### Native audio ducking

When enabled, Nuvi uses the macOS VoiceProcessingIO capture path to request
native ducking instead of changing the system output volume directly. The
selected route remains explicit and read-only from Nuvi's perspective. If a
route cannot provide native ducking, Nuvi reports that limitation and suggests
disabling ducking or selecting a supported microphone.

### Push-to-talk and capture reliability

- Modifier-only push-to-talk activates only when the modifier is held alone;
  ordinary shortcuts cancel activation before recording starts.
- Capture sessions now isolate native lifecycle state, bound callback admission,
  and publish audio through a bounded ring outside the realtime callback.
- Route changes, cancellation, cleanup, and late callbacks are handled through
  explicit lifecycle paths rather than shared session state.

### Models, downloads, and silence control

- Model downloads can be paused and resumed while retaining the provider's
  on-disk cache.
- The catalog adds **Whisper Large v3 Turbo** as a faster, lower-footprint
  option for Apple Silicon.
- Optional voice activity detection can stop a session after speech followed by
  sustained silence, with a user-configurable threshold.

### Pill and visualizer

- The floating pill supports 17 magnetic snap anchors with an animated drop-zone
  overlay across the active display.
- The ferrofluid visualizer adds organic and magnetic-spike styles, granular
  core and droplet controls, and multi-band bass/mid/treble FFT driving.
- Active-display placement and completion feedback are kept consistent while
  capture starts, stops, or is cancelled.

## Reliability and safety

- Audio input and native unit teardown use bounded cleanup paths and diagnostic
  state rather than changing the system default device or output volume.
- Speech, model, and download flows use bounded windows, cancellation guards,
  and stale-attempt protection.
- Clipboard fallback failures are surfaced instead of being reported as a
  successful insertion.

## Compatibility and distribution

- **Minimum OS**: macOS **26.0**.
- **Architecture**: Apple Silicon (`arm64`).
- **Distribution**: free Homebrew distribution signed with the available Apple
  Development identity and **not notarized**. macOS may block the first launch;
  clear the download quarantine once if needed:

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Nuvi.app"
  ```

Transcription models are not bundled in the application archive. They are
downloaded or loaded by the selected engine on demand.

## Known limitations

- Native ducking depends on the selected audio route and its VoiceProcessingIO
  support. Unsupported routes require ducking to be disabled or another input
  device to be selected.
- Accessibility insertion and model-dependent runtime behavior still require
  validation in the target editor and on the target machine.
- This release preparation does not claim physical microphone, Bluetooth
  acoustics, DSP, or push-to-talk hardware validation.

## Install or upgrade

```bash
brew tap ForLess01/tap
brew update
brew upgrade --cask nuvi
```

For a first installation, use `brew install --cask nuvi` instead of the
upgrade command. The cask prints the first-launch Gatekeeper caveat for this
free, non-notarized distribution.
