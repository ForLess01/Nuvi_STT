# Nuvi 2.2.1

Nuvi 2.2.1 is a fix release for repeated push-to-talk capture when native audio
ducking is enabled. It hardens capture recovery after listener and native
cleanup failures so a prior session does not prevent a subsequent capture or
allow overlapping VoiceProcessingIO sessions.

## Fixes

- Prevent VoiceProcessingIO capture overlap when cleanup of an earlier session
  fails.
- Allow a new capture attempt to proceed after a callback arrives for a disposed
  listener.

## Compatibility and distribution

- **Minimum OS**: macOS **26.0**.
- **Architecture**: Apple Silicon (`arm64`).
- **Distribution**: free and not notarized. The release bundle uses the existing
  Apple Development signing configuration; macOS may block the first launch.
  If needed, clear the download quarantine once:

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Nuvi.app"
  ```

Transcription models are not bundled in the application archive. They are
downloaded or loaded by the selected engine on demand.

## Validation limits

The release-preparation work does not independently validate a physical
microphone, repeated PTT operation, Bluetooth acoustics, DSP behavior, or
audio-route-specific ducking. The reported installed test build is not a
substitute for reproducible hardware validation. Accessibility insertion and
model-dependent runtime behavior also require validation on the target machine.

## Install or upgrade

After this version is published, upgrade with:

```bash
brew tap ForLess01/tap
brew update
brew upgrade --cask nuvi
```

For a first installation after publication, use `brew install --cask nuvi`.
The cask prints the first-launch Gatekeeper caveat for this free,
non-notarized distribution.
