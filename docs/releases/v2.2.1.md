# Nuvi 2.2.1

Nuvi 2.2.1 is intended as a fix release for repeated push-to-talk capture when
native audio ducking is enabled. In the serialized PTT flow, it hardens
recovery after failed native teardown and route-listener removal failures that
remain after AudioUnit disposal.

## Update notices

- Check the public GitHub stable release at startup and every 12 hours, without
  blocking dictation. Persist check throttling and server backoff across restarts.
- Show the installed and available version, check status, last check, manual
  refresh, and a release-page action in Settings → Configuration and Home.
- Announce each newer version with a native macOS notification after contextual
  permission approval. Denied or unavailable notifications never hide the
  Settings notice; network failures retain a previously validated available release.
- Accept only stable versions and official HTTPS Nuvi release pages. Updates are
  advisory: no automatic downloads, installation, or shell commands.

Nuvi 2.2.0 needs one manual upgrade after publication to receive future notices.
This update-notice work does not alter audio, ducking, or push-to-talk.

## Fixes

- Prevent overlapping VoiceProcessingIO capture sessions in the serialized PTT
  flow when teardown of an earlier session fails.
- Handle route-listener removal failure that remains after AudioUnit disposal
  so it does not block a subsequent serialized PTT capture.

## Publication status

This local candidate is **not published** and is not ready to be treated as an
installable release. Its strict code-signature verification fails with
`CSSMERR_TP_NOT_TRUSTED`, and Gatekeeper assessment returns an internal
code-signing error. The app has not been independently validated on physical
microphone/PTT hardware.

## Compatibility and distribution

- **Minimum OS**: macOS **26.0**.
- **Architecture**: Apple Silicon (`arm64`).
- **Distribution policy**: free, Apple Development signing, and not notarized.
  The current candidate's signature trust is not verified. Removing download
  quarantine does not resolve a signature-trust failure and is not a safe
  workaround.

Transcription models are not bundled in the application archive. They are
downloaded or loaded by the selected engine on demand.

## Validation limits

The release-preparation work does not independently validate a physical
microphone, repeated PTT operation, Bluetooth acoustics, DSP behavior, or
audio-route-specific ducking. The reported installed test build is not a
substitute for reproducible hardware validation. Accessibility insertion and
model-dependent runtime behavior also require validation on the target machine.
The prior local `swift test` run exited 1 without a conclusive failure summary;
this candidate must not be described as fully verified.

## Install or upgrade

After this version is published, upgrade with:

```bash
brew tap ForLess01/tap
brew update
brew upgrade --cask nuvi
```

For a first installation after publication, use `brew install --cask nuvi`.
The cask prints the first-launch Gatekeeper caveat for this free,
non-notarized distribution.
