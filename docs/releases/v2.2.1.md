# Nuvi 2.2.1

Nuvi 2.2.1 improves repeated push-to-talk capture with native audio ducking and
adds automatic update notices. The serialized PTT flow hardens recovery after
failed native teardown and route-listener removal failures that remain after
AudioUnit disposal; the update notices do not alter that audio implementation.

## Update notices

- Check the public GitHub stable release at startup and every 12 hours, without
  blocking dictation. Persist check throttling and server backoff across restarts.
- Show the installed and available version, check status, last check, manual
  refresh, and a release-page action in Settings → Configuration and Home.
- Announce each newer version with a native macOS notification after contextual
  permission approval. Denied or unavailable notifications never hide the
  Settings notice; network failures retain a previously validated available release.
- Accept only stable versions and official HTTPS Nuvi release pages. Updates are
  advisory: no automatic downloads, installation, or shell commands.

Nuvi 2.2.0 needs one manual upgrade after publication to receive future notices.
This update-notice work does not alter audio, ducking, or push-to-talk.

## Fixes

- Prevent overlapping VoiceProcessingIO capture sessions in the serialized PTT
  flow when teardown of an earlier session fails.
- Handle route-listener removal failure that remains after AudioUnit disposal
  so it does not block a subsequent serialized PTT capture.

## Package verification

Fresh normal-permissions verification of the rebuilt app passes strict, deep
code-signature verification. Package checks establish signature integrity, not
Gatekeeper approval or hardware validation.

## Compatibility and distribution

- **Minimum OS**: macOS **26.0**.
- **Architecture**: Apple Silicon (`arm64`).
- **Version/build**: **2.2.1 (6)**.
- **Distribution policy**: free, stable Apple Development signing with Hardened
  Runtime; not notarized. The audio-input entitlement is present in the signed
  app. Gatekeeper rejects this distribution under its execution policy; strict
  signature integrity nevertheless passes. This is not Developer ID or notarized
  distribution approval. Do not use quarantine removal to excuse signature errors.

Transcription models are not bundled in the application archive. They are
downloaded or loaded by the selected engine on demand.

## Validation limits

- All **14 injected update-service regression tests** pass without live network,
  notification permission, app launch, or microphone access. The release build
  passes, and the app's strict signature and effective entitlement are verified.
- The full test suite remains incomplete: it terminates with signal 5 in
  `SpeechAnalyzerEngineTests/testAnalyzerInputQueueCountsDropsAndPreservesOldestSlices`.
  Independent comparison reproduces that failure on the unchanged `44e883c`
  baseline as well as the updater candidate. This establishes that the failure
  predates the updater, not its root cause; do not describe the suite as passing.
- Actual macOS notification delivery, notification clicks, runtime Settings UI,
  keyboard/screen-reader behavior, physical microphone/PTT, Bluetooth acoustics,
  DSP/route-specific ducking, Accessibility insertion, and model-dependent runtime
  behavior have not been independently validated by this release preparation.

## Install or upgrade

Upgrade with:

```bash
brew tap ForLess01/tap
brew update
brew upgrade --cask nuvi
```

For a first installation, use `brew install --cask nuvi`.
The cask prints the first-launch Gatekeeper caveat for this free,
non-notarized distribution.
