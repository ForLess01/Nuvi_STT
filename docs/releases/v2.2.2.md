# Nuvi 2.2.2

A push-to-talk audio-lifecycle fix, plus clearer setup and development documentation.
**Build 7 · macOS 26 or later · Apple Silicon**

## Audio fixes

- Release the complete VoiceProcessingIO graph after every PTT session instead
  of retaining a stopped, initialized unit between presses. This addresses the
  ownership issue investigated after reports of stuck ducking and unresponsive
  output-volume controls.
- Finish each session's PCM stream after ordered native teardown. Keep callback
  lifetime, quarantine recovery, negotiated buffer capacity and off-main control.
- Preserve native audio ducking, the non-ducking capture path and the quiet
  preparation UI. No system-volume or default-device writes were added.

Recreating the native graph may increase startup latency compared with reuse.
The user reported the installed correction working well; that is not a complete
hardware compatibility matrix or proof of every OS/driver failure's root cause.

## Documentation

- A shorter README with feature tables and expandable details for engines,
  permissions, privacy and updates.
- Separate development and release guides, including the limitations of the
  existing delete-first installation helper.
- Documentation media separated from runtime resources; reference artwork
  retained rather than deleted.

## Upgrade

```bash
brew update
brew upgrade --cask nuvi
```

Or download `Nuvi.zip` from this release. Quit Nuvi before replacing an existing
copy and preserve a rollback. Model downloads are separate from the app archive.

## Verification and distribution limits

The audio correction has focused regression coverage and user-reported local
acceptance. The known full-suite interruption in
`SpeechAnalyzerEngineTests/testAnalyzerInputQueueCountsDropsAndPreservesOldestSlices`
(signal 5) is not a passing full suite. Release-specific checks are recorded in
[the release log](../../odd/tasks/release-2-2-2.md).

This release uses the existing Apple Development signing identity and is **not
notarized**. Signature validation is not Gatekeeper approval. macOS may block the
first launch; review the release before allowing it through Privacy & Security.
No global security-policy changes are required or performed by this release work.
