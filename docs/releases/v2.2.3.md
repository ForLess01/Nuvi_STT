# Nuvi 2.2.3

Reliability corrections across transcription, model storage, insertion and local distribution.
**Build 8 · macOS 26 or later · Apple Silicon**

## What changed

| Area | Corrections |
| --- | --- |
| Transcription | Standard preserves segmented finals without duplicating cumulative results. Whisper LIVE drains bounded audio intake independently of partial inference. Parakeet cleanup covers error and cancellation paths. |
| History and models | Cleared legacy history cannot reappear through migration. Download attempts, published models and active readers have separate filesystem ownership; inventory scans run off MainActor and validate the actual cache. |
| Text insertion | Standard/LIVE waits suspend instead of blocking MainActor. A shared FIFO orders cancellation rollback and replacement output, with target/security and clipboard-ownership checks. |
| Shortcuts, translation and pill | Conflicting shortcuts are rejected; registration failures are visible. Preparation and translation have separate bounded phases when the framework permits it. Notice timers own their generation; repeated pill layouts are coalesced. |
| Audio and distribution | FFT bands remain within available bins at low sample rates. Publisher idle polling backs off within bounded latency and exposes loss counters. Build/signing fails closed; installation verifies a fresh rollback before replacement. |

Native VoiceProcessingIO ducking and complete per-PTT teardown are preserved.

## Upgrade

```bash
brew update
brew upgrade --cask nuvi
```

Or download `Nuvi.zip`. Quit Nuvi before replacement and preserve a rollback.
Models are separate from the app archive. Existing installed local candidates
are not automatically replaced by this publication.

## Verification and limits

The implementation candidate completed 341 deterministic tests: **338 passed,
3 opt-in probes skipped**, plus **21 distribution fixture tests**. The release
package receives fresh build, signature, archive and independent verification;
release-specific evidence is recorded in [the release log](../../odd/tasks/release-2-2-3.md).
No new microphone, real-model inference or physical compatibility claim is made
from those checks. Supplemental native reviews were not completed; independent
verification is not represented as a native review receipt.

Model isolation uses additional disk space. SDK attempt directories are retained
when internal writer quiescence cannot be proven; they are not installed-model
inventory. Private read snapshots are reused while owned and cleaned on release.
See [reliability boundaries](../development.md#reliability-boundaries).

This release uses the existing **Apple Development signature and is not
notarized**. Signature integrity is not Gatekeeper approval. macOS may block first
launch; review the release before allowing it in Privacy & Security. Do not
disable Gatekeeper globally. No trust, quarantine or TCC policy is changed by
this release work.
